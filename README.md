# Telegram-бот «КОРАН»

Арабский текст + английская транскрипция в красивом PDF, дуа и аяты каждые 30 минут.

## Запуск
1. Создайте бота в @BotFather, получите токен.
2. Загрузите эти файлы на GitHub, затем на сервер (bothost.ru).
3. Установите зависимости: `pip install -r requirements.txt` (Python 3.10+).
4. Задайте переменную окружения `BOT_TOKEN` и запустите: `python bot.py`

При первом запуске бот сам скачивает:
- текст Корана (арабский Усмани, английская транскрипция, русский перевод Кулиева) с api.alquran.cloud,
- шрифты Amiri / Amiri Quran (лицензия OFL).
Нужен выход в интернет. Данные кешируются в `data/`, `fonts/`, готовые PDF в `pdf_cache/`.

## Чтецы
После выбора суры доступны кнопки с чтецами (Ясир ад-Досари, Абдуллах аль-Малик).
Бот сам находит нужную суру на mp3quran.net. Список чтецов меняется в `RECITERS` в `bot.py`
(поиск по арабскому имени). Файлы до 20 МБ приходят прямо в чат, большие открываются по кнопке-ссылке.

## Регион и время намаза
Кнопка «Регион / время намаза» в главном меню: страна → город (Таджикистан, Узбекистан, Россия)
или «Другой город» (ввод латиницей: `Osh, Kyrgyzstan`). Время берётся с api.aladhan.com,
в каждое время намаза бот присылает сообщение с дуа из Корана. Команда `/region` открывает выбор региона.
Метод расчёта: Россия по ДУМ РФ, остальные по MWL, аср по ханафитскому мазхабу
(Махачкала и Грозный по шафиитскому). Время расчётное и может отличаться от календаря мечети на несколько минут.

## Мини-приложение «Проверь своё чтение»
Файл `index.html` в корне репозитория. Включите GitHub Pages (Settings → Pages → Branch: main, папка root),
адрес будет `https://<логин>.github.io/<репозиторий>/`. Если он отличается от
`https://del1vo.github.io/Quran-/`, задайте переменную окружения `MINIAPP_URL`.
В боте кнопка «🎙 Проверить себя» отправляет сообщение с кнопкой «✅ Проверить», а также ставится
кнопка «🎙 Проверить» в меню бота. Текст суры приложение берёт с api.alquran.cloud.
Распознавание речи работает через браузерный Web Speech API (язык ar-SA): в Chrome и Safari работает,
внутри Telegram на части устройств нет (тогда приложение предлагает открыть его в браузере).

## Мини-приложение на домене bothost
Бот сам отдаёт `index.html` по порту `PORT` (по умолчанию 3000). На вкладке «Домен» в bothost
включите «Использовать свой домен», оставьте порт 3000 и сохраните. Адрес вида
`https://bot-....bothost.tech` и есть адрес мини-приложения (переменная `MINIAPP_URL`, если он другой).

## Команды
/start (подписка на рассылку), /stop (отписка), /dua (дуа/аят сейчас)

## Свои дуа (хадисы и др.)
Файл `data/extra_duas.json` (проверенные тексты из надёжных источников):
```json
[{"title": "Название", "source": "Источник", "ar": "...", "tr": "...", "ru": "..."}]
```
Они подмешиваются в рассылку.

Если диск сервера временный, `data/subscribers.json` может пропадать при перезапуске.
