# Telegram-бот «КОРАН»

Арабский текст + английская транскрипция в красивом PDF, дуа и аяты каждые 30 минут.

## Запуск
1. Создайте бота в @BotFather, получите токен.
2. Загрузите эти файлы на GitHub, затем на сервер (bothost.ru).
3. Установите зависимости: `pip install -r requirements.txt` (Python 3.10+).
4. Задайте переменную окружения `BOT_TOKEN` и запустите: `python bot.py`

При первом запуске бот сам скачивает:
- текст Корана (арабский Усмани, английская транскрипция, русский перевод Кулиева) с api.alquran.cloud,
- шрифты Amiri / Amiri Quran (лицензия OFL).
Нужен выход в интернет. Данные кешируются в `data/`, `fonts/`, готовые PDF в `pdf_cache/`.

## Команды
/start (подписка на рассылку), /stop (отписка), /dua (дуа/аят сейчас)

## Свои дуа (хадисы и др.)
Файл `data/extra_duas.json` (проверенные тексты из надёжных источников):
```json
[{"title": "Название", "source": "Источник", "ar": "...", "tr": "...", "ru": "..."}]
```
Они подмешиваются в рассылку.

Если диск сервера временный, `data/subscribers.json` может пропадать при перезапуске.
